## 🎯 What I do

I work at the intersection of **data** and **software engineering** — building systems where the data pipeline, the model and the product are the same thing.

<table>
<tr>
<td width="50%">

### 📊 Data
The full lifecycle: collection and cleaning, exploratory analysis, statistical testing, feature engineering, predictive modeling and reporting.

- ETL and data collection from open APIs (TSE, IBGE, marketplaces)
- Statistical inference, ANOVA, PCA, feature selection
- Models: Random Forest, XGBoost, SVM, MLP, KNN
- Evaluation, explainability (SHAP) and Markdown/BI reports

</td>
<td width="50%">

### 💻 Software
Production-grade backends and full-stack products, containerized and documented.

- APIs in **Django/DRF**, **FastAPI** and **Flask**
- Auth and security: JWT, RBAC, PII encryption, rate limiting
- React + Vite frontends, Dockerized services
- Web automation with **Playwright** and LLM integration

</td>
</tr>
